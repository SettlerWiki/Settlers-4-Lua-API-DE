# SU.GameData

{% hint style="info" %}
Dies ist ein **sehr experimenteller Bereich**!

Es wurden hier sehr viele Parameter aus dem Spiel herausgeführt, die nun mit den folgenden Funktionen manipuliert werden können. Die Parameter werden aus den xml-Dateien im Ordner GameData geladen, die aber von Settlers United bei jedem Start überschrieben werden, damit alle Spieler dieselben GameData haben, sonst kommt es zu Desyncs.

Mit den hier angeführten Funktionen, können nun Parameter vom Spiel nun live verändert werden.

**Eine Veränderung der Parameter muss aber nicht zwingend zu einer Änderung im Spiel führen**, da einige nur beim Start geladen und dann nicht wieder abgefragt werden.

Manche Parameter können aktuell nicht verändert werden.

Manche Parameter werden zu **Abstürzen (FEs)** führen.

Manche Parameter sind zwar veränderbar, führen aber zu keiner Änderung, weil SU sie intern überschreibt. In solchen Fällen diese bitte auf Discord melden, dann können sie schrittweise richtiggestellt werden.

**Die Parameter müssen alle noch genauer untersucht werden, dementsprechend kann sich hier im Laufe der Zeit noch viel verändern...**
{% endhint %}
