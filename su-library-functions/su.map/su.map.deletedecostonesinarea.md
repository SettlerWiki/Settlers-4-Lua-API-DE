# SU.Map.DeleteDecoStonesInArea

## SU.Map.DeleteDecoStonesInArea(x, y, radius)

Entfernt alle **Deko**-Steine im Bereich, **nicht** abbaubare.

#### Parameter

* `x,y`: Koordinaten
* `radius`: Radius

#### Beispiel

```lua
SU.Map.DeleteDecoStonesInArea(50, 70, 15)
```
